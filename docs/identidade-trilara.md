# Identidade visual da Trilara

**Ideia:** trilha + Lara. O nome liga a descoberta de um caminho claro à autoria do projeto. É uma proposta inicial; antes de uso comercial, consulte disponibilidade de marca e domínio.

**Assinatura:** Conhecimento conectado.

**Logo:** um `T` formado por caminhos com três pontos. Os pontos representam sistemas, documentos e pessoas. Arquivos vetoriais: `public/brand/trilara-mark.svg`, `trilara-logo-light.svg` e `trilara-logo-dark.svg`.

**Imagem para links:** `src/app/opengraph-image.png` (1200 × 630), gerada com `npm run brand:og`.

| Papel | Cor | Hex |
| --- | --- | --- |
| Fundo e texto escuro | Azul profundo | `#0B1724` |
| Ação principal | Verde água | `#0B8B80` |
| Destaque | Menta | `#5CE0CC` |
| Fundo claro | Névoa | `#F5FAF9` |
| Acento humano | Pêssego | `#F6B786` |

Use o logo claro sobre fundos claros e o logo escuro sobre fundos escuros. Mantenha o texto em azul profundo ou branco para contraste. A vitrine pública tem mockup com números explicitamente fictícios.
