# Publicação no LinkedIn

Quero compartilhar um projeto pessoal que está em desenvolvimento: o **Trilara**.

A ideia surgiu de uma dificuldade comum em equipes que usam vários sistemas: encontrar o manual certo e entender como executar um processo nem sempre é simples. Criei o Trilara para reunir sistemas e documentação em um só lugar, com busca, páginas de orientação e guias passo a passo.

O sistema também permite criar e editar manuais, organizar conteúdos, cadastrar usuários e definir permissões.

Preparei uma demonstração interativa com dados fictícios para mostrar a experiência:
https://trilara-rho.vercel.app

O código do projeto está no GitHub:
https://github.com/JoaoGabriel0320/trilara

Vou compartilhar algumas telas neste post e continuar mostrando a evolução do Trilara por aqui.
